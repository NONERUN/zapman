# План

Рабочий статус: **alpha**. Политика ломающих изменений — в [`AGENTS.md`](AGENTS.md).

## Целевое состояние

В корне остаётся **ровно один** `.bat`. Он только проверяет, что среда готова к целям ниже, и при успехе запускает PowerShell. Вся остальная логика — `.ps1` (GUI, служба, стратегии, списки, тесты).

Сейчас в корне один `.bat` (`zapret.bat`). Стратегии — `strategies/*.ps1`. Служба/диагностика — `utils/service.ps1`. Новые `.bat` не добавлять. При переносе старый `.bat` удалять, не оставлять рядом `.ps1` «на всякий случай».

Проверки единственного `.bat` (минимум):

- Есть `powershell.exe` (Windows PowerShell), версия ≥ 3.0, цель — **5.1**.
- Есть `-STA`, WinForms / .NET для GUI.
- Windows 10 LTSC (и новее с рабочим столом): допнастроек нет — проверка проходит на inbox.
- Windows 7 SP1 x64: если нет WMF / .NET 4.5+ — bat пишет, чего не хватает, и выходит с ошибкой. Сам WMF не ставит.
- Каталог `bin/` на месте (иначе GUI и обход всё равно не стартуют). После цели 4 — в нём `winws2.exe` и Lua той же поставки zapret2.

Имя файла входа: `zapret.bat`. Он валидирует среду и вызывает `utils\gui.ps1`.

## Цели

Единственный `.bat` подтверждает, что эти цели вообще могут работать. Реализация целей — в `.ps1`.

### 1. Работа в Windows PowerShell 5.1

Интерпретатор — `powershell.exe` 5.1 (не PowerShell 7 / `pwsh`).

Готово, когда:

- Единственный `.bat` отказывает понятно, если PowerShell слишком старый (типичный Win7 без WMF = 2.0).
- Все `.ps1` (GUI, служба, стратегии) идут на 5.1 без синтаксиса PowerShell 7.
- StrictMode и разворачивание массивов из одного элемента не роняют GUI.
- Нигде нет вызова `pwsh`.

### 2. Windows 10 LTSC без допнастроек, Windows 7 — с допнастройками

Готово, когда:

- На Windows 10 Enterprise LTSC (2016 / 1607 и новее, с рабочим столом) проверка `.bat` проходит на inbox PS 5.1 и .NET 4.x. Без WMF, без `pwsh`, без .NET SDK.
- На Windows 7 SP1 x64 проверка проходит только после допнастройки: WMF 3.0+ (лучше WMF 5.1) и .NET 4.5+. Сообщение об ошибке перечисляет недостающее. Когда GUI/вход стабилизируются — это же описано в README.
- Для обхода на Windows 7 по-прежнему нужны Win7-файлы WinDivert в `bin/` (это не GUI).
- 32-bit и Server Core / установка без рабочего стола — вне цели.

### 3. GUI

Готово, когда:

- Есть окно WinForms на `.ps1`: выбор стратегии, Start / Stop, Install Service / Remove Services, Game Filter, IPSet, статус обхода и службы.
- Вход: единственный `.bat` (валидация) → UAC при необходимости → GUI `.ps1` с `-STA`.
- Стратегии — `strategies/*.ps1` (не `general*.bat` в корне). Служба и фильтры — `utils/service.ps1` и GUI (не `service.bat`).
- Поведение службы и фильтров там, где GUI их закрывает, совпадает с текущей логикой (порядок Remove, backup IPSet, имя стратегии в реестре).
- README описывает один `.bat` и GUI, без меню из десятков `.bat`.
- Процесс обхода — целевой бинарник (после цели 4: `winws2.exe`, не `winws.exe`).

GUI, валидатор и раскладка `.ps1` для целей 1–3 на месте. Осталось: переход на zapret2.

### 4. Переход на zapret2

Движок — [bol-van/zapret2](https://github.com/bol-van/zapret2): на Windows это **winws2** + WinDivert, стратегии — **Lua**, не флаги `nfqws`/`winws` первого поколения.

Готово, когда:

- В `bin/` бинарники и Lua **одной** поставки zapret2 (`winws2.exe`, WinDivert, `zapret-lib.lua` / `zapret-antidpi.lua` и связанные файлы). Не смешивать с `winws.exe` из zapret1 / zapret-win-bundle.
- GUI и служба запускают `winws2.exe`. Статус смотрит `winws2`, не `winws`.
- Стратегии задают Lua (`--lua-init`, `--lua-desync` и профили zapret2), а не длинные `--dpi-desync*` из winws1.
- Каждая текущая стратегия (`general*.bat` и аналоги) имеет преемника на zapret2. Имя файла/подпись можно сменить; набор не выкидывать. Старые `general*.bat` после переноса **удалены**.
- Без режима «оба движка» и без алиасов `winws` → `winws2`.
- Единственный `.bat` проверяет наличие `winws2.exe` (и Lua, если без них запуск бессмыслен).
- Win7: по-прежнему отдельные файлы WinDivert из поставки zapret2 для win7, если автор их даёт; не тащить winws1 «ради семёрки».

Источник истины по флагам и Lua — мануал zapret2, не README этой сборки и не старые `general*.bat`.

## Вне скоупа (пока)

- Перенос GUI на `pwsh` 7 / WinUI 3 / WPF.
- Обратная совместимость обвязки (старые `.bat` лаунчера, флаги winws1, раскладки). Набор стратегий сохранять, имена можно менять — [`AGENTS.md`](AGENTS.md).
- Свои Lua-атаки и новые техники обхода без отдельной задачи; обвязка только запускает zapret2.
- Диагностика, тесты, hosts, auto-update внутри GUI — отдельные `.ps1`, не раздувать окно без задачи.
