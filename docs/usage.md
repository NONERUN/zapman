# Использование

Программа — один файл `zapman.exe` (GUI). Консольной версии (CLI) пока нет. Макеты окон: [Окна GUI](ui/index.md).

Нужна **Windows 10** или новее, x64. Окна рисует WebView2 (Microsoft Edge WebView2 Runtime). В Windows 10 и 11 он обычно уже стоит. Windows 7 и 8 не поддерживаются.

## Secure DNS

Без безопасного DNS часть сайтов может не открываться, даже если стратегия живая.

- **Chrome:** «Использовать безопасный DNS», поставщик **не** «по умолчанию».
- **Firefox:** DNS через HTTPS, режим «Персональный», URL вручную, например `https://dns.google/dns-query` (Cloudflare иногда недоступен).
- **Windows 11:** Secure DNS в настройках ОС — [инструкция](https://remontka.pro/dns-over-https-windows-11/).
- **Keenetic:** в роутере включите «Транзит запросов», иначе DNS на компьютере может не заработать.

## Установка

1. Скачайте zip/rar со [страницы релизов](https://github.com/NONERUN/zapman/releases/latest) **этого** репозитория.
2. Свойства архива → «Разблокировать» (7-Zip и PeaZip часто не требуют этого).
3. Распакуйте в путь **без** кириллицы, пробелов и спецсимволов. `zapman.exe` ищет `bin/`, `strategies/` и `lists/` рядом с собой.
4. Обновление: скопируйте старую папку `user/` в новую распаковку.
5. Запустите `zapman.exe`. Права администратора exe просит сам (UAC).

Версия программы — в заголовке окна (`Zapret Manager v…`) и в первой строке окна «Статус и журнал». Сборка не из релиза показывает `dev-<коммит>`.

## Главное окно

- **Старт службы** — запускает уже установленную службу `zapret`. Если службы нет, кнопка серая.
- **Стоп** — останавливает `winws.exe` / `winws2.exe` и службу, если она запущена.
- **Снять службы** — удаляет службу `zapret` и драйверы WinDivert / WinDivert14. Без дополнительного вопроса. Задание `zapman-tray` не удаляет.
- **Стратегия...** — выбор стратегии и движка. См. ниже.
- **Игры...** — игровые модули. См. [Игры](#игры).
- **Settings** на этом же окне: Game Filter, IPSet Filter, Auto-Update Check, «Иконка в трее», **Fake...**.
- **Tools:** «Скачать ipset», «Сверить hosts», «Проверить версию», «Диагностика».
- Клик по блоку **Status** — окно «Статус и журнал»: версия, состояние службы и WinDivert, последняя ошибка движка и журнал действий. Кнопка **Копировать** кладёт весь текст в буфер.

Язык RU/EN — радио справа вверху. Выбор пишется в `user/config.json`.

Крестик главного окна: при включённой «Иконке в трее» окно прячется в трей, программа работает дальше; при выключенной — программа закрывается. Служба и запущенный движок от этого не останавливаются.

## Стратегия...

Список — стратегии каталога `strategies/`. Метки: ` (запущена)` — работает сейчас, ` (служба)` — стоит в службе. Серая строка не собирается для выбранного движка.

Радио **winws** / **winws2** выбирает движок для следующего действия. В `user/config.json` (`engine`) он попадает при **Установить службу**, **Запустить без установки** или **Прогнать тесты**. Закрыть диалог крестиком — `engine` не меняется.

Перед запуском файлы движка в `bin/` сверяются с SHA256 из `bin/versions.json`. Не совпали или нет файла — кнопки запуска и установки серые, другой движок сам не подставляется.

- **Установить службу** — ставит службу `zapret` (автозапуск) с выбранной стратегией, движком, Game Filter и играми, стартует её и закрывает диалог. Смена фильтра, игр или движка потом на службу не действует, пока не нажать эту кнопку снова.
- **Запустить без установки** — запускает выбранную стратегию без службы. Если обход уже работает, сначала спрашивает, остановить ли его. Если работает чужой `winws` (запущен не zapman) — спрашивает, остановить ли его. После перезагрузки Windows этого процесса не будет.
- **Прогнать тесты** — закрывает диалог и открывает окно тестов. См. [Тесты](#тесты).
- **Ни одна не подходит** — после вопроса: `netsh winsock reset`, `netsh int ip reset all`, `netsh winhttp reset proxy`, `ipconfig /flushdns`, затем вопрос про перезагрузку.

## Тесты

В окне «Прогнать тесты» выберите тип и стратегии (кнопки **Все** / **Нет**):

- **Обычный (HTTP / ping)** — по каждой цели `curl` HTTP, TLS 1.2, TLS 1.3 и ping.
- **DPI-проверки (TCP 16-20)** — проверки DPI. На время прогона IPSet Filter = `any`, после прогона список возвращается.

Служба `zapret` на время тестов снимается, после прогона ставится снова в том же виде и стартует, если работала до тестов. Стратегия, запущенная без установки, после прогона запускается снова. Окно: подготовка, вкладка на каждую стратегию (ошибка — красная ячейка, текст можно копировать), итоги с лучшей стратегией. Лог — в папке `test-results/`.

## Settings

**Game Filter** подставляет порты игр в стратегию. В `user/config.json` — ключ `gameFilter`; диапазоны — `gameFilterTcp` / `gameFilterUdp` (по умолчанию `1024-65535`).

| GUI | `user/config.json` | Порты TCP/UDP |
|---|---|---|
| `disabled` | `disabled` | `12` / `12` |
| `TCP and UDP` | `all` | `1024-65535` / `1024-65535` |
| `TCP only` | `tcp` | `1024-65535` / `12` |
| `UDP only` | `udp` | `12` / `1024-65535` |

Порт `12` значит «фильтр выключен». После смены, если служба стоит, GUI спрашивает, поставить ли её снова (открывает «Стратегия...»). Без службы: Стоп, затем запуск из «Стратегия...».

**IPSet Filter** — содержимое `user/ipset-all.txt` (движок читает его при старте):

| Значение | Файл |
|---|---|
| `none` | одна строка `203.0.113.113/32` (ни один IP не подходит) |
| `loaded` | скачанный или свой список |
| `any` | пустой файл (подходит любой IP) |

При переходе с `loaded` на `none` или `any` список уходит в `user/ipset-all.txt.backup`; `loaded` возвращает его. Нет копии — ошибка «Нет копии списка IPSet»: сначала **Скачать ipset**. После смены, если служба стоит, GUI спрашивает, перезапустить ли её. Без службы: Стоп, затем запуск из «Стратегия...».

**Auto-Update Check** — при старте GUI сверяет версию с GitHub (как **Проверить версию**). Проверка не блокирует окно.

**Иконка в трее** — иконка в области уведомлений и задание планировщика `zapman-tray`: при входе в Windows оно запускает `zapman.exe --tray` с наивысшими правами (без UAC), главное окно при этом не показывается. По умолчанию включено. Меню трея: три строки статуса, **Открыть**, **Старт службы**, **Стоп**, **Выход**. Двойной клик — главное окно. Крестик главного окна при включённой галке только прячет окно в трей; **Выход** закрывает программу. Стратегия, запущенная без службы, после выхода продолжает работать (как в PS-версии): остановите её кнопкой **Стоп** до выхода. Стратегию из трея не меняют. Снять галку — нет иконки и нет задания. **Снять службы** задание не трогает.

Цвет иконки трея и окон — тот же, что у плашки на главном окне:

- **синяя** — обход работает (запущена служба `zapret` или winws / winws2), всё в порядке;
- **серая** — обход остановлен, проблем нет (например, нажали «Стоп»);
- **жёлтая** — что-то не так, но обход работает или может запуститься: последнее действие не удалось, а обход работает; в `bin` нет `WinDivert64.sys`, а обход ещё работает; запущены и winws.exe, и winws2.exe; в `strategies` нет стратегий;
- **красная** — обход не работает и не запустится: последнее действие не удалось; в `bin` нет `WinDivert64.sys`; WinDivert завис (STOP_PENDING).

При жёлтой и красной иконке причина — первая строка подсказки и меню трея. Красная от неудачного действия держится до успешного запуска. Иконка меняется при обновлении статуса (раз в 2 с и после действий).

Окна и трей — один процесс. Второй запуск того же `zapman.exe` показывает главное окно уже запущенного; второй запуск с `--tray` ничего не делает. Если запущен другой `zapman.exe` (новая сборка на месте старой или копия из другой папки), старый процесс закрывается и уступает место новому. winws и служба при этом продолжают работать: если служба поставлена из старого каталога, новый GUI покажет, что она устарела.

**Fake...** — оба слота сразу (Discord UDP и Game UDP). Список — файлы `strategies/fakes/*.bin`. Выбранный файл копируется в `user/fakes/ACTIVE_DISCORD_UDP.bin` или `user/fakes/ACTIVE_GAME_UDP.bin`. Пока файла нет, окно показывает дефолт каталога (`quic_initial_rutube_ru.bin` / `quic_initial_4pda_to.bin`); запуск, установка службы и тесты создают файл из этого дефолта. Выбранный файл программа не перезаписывает. Движок читает их при старте: если служба стоит, GUI спрашивает, перезапустить ли её; без службы — Стоп, затем запуск из «Стратегия...».

## Tools

- **Скачать ipset** — скачивает `.service/ipset-service.txt` из репозитория на GitHub в `user/ipset-all.txt`. Окно с прогрессом, загрузку можно отменить.
- **Сверить hosts** — скачивает шаблон `.service/hosts` из репозитория и сравнивает с hosts Windows. Если нужно обновить: **Копировать шаблон** и **Открыть hosts** (Блокнот). См. [Проблемы](troubleshooting.md#не-работает-telegram-веб-или-бесконечное-подключение-к-голосовому-чату-discord).
- **Проверить версию** — сравнивает версию сборки с тегами GitHub. Есть новее — предлагает открыть страницу релизов. Архив сама не скачивает. Сборке для разработки (`dev-…`, не из релиза) обновление не предлагается: кнопка только показывает последний релиз.
- **Диагностика** — список проверок (конфликтующие службы, путь, DNS, WinDivert, кэш Discord и другие) с отметкой OK / предупреждение / ошибка. У части строк есть кнопка **Исправить**: снять конфликтующие службы, снять WinDivert, очистить кэш Discord. После действия список строится заново.

## Игры

**Игры...** — галки игровых модулей из `strategies/games/`. Под названием игры — короткое описание модуля на языке интерфейса. Правила выбранных игр идут перед правилами стратегии и работают даже при Game Filter = `disabled`. Выбор пишется в `user/config.json` (`games`). Применение — как у Game Filter: служба — поставить снова, без службы — Стоп и новый запуск.

Под игрой могут быть её опции (галки с отступом). Опции выключенной игры недоступны, но своё значение сохраняют. В `user/config.json` попадают только опции, отличные от значения по умолчанию (`gameOptions`). Смена опции — как смена игр: служба — поставить снова (служба со старыми опциями считается устаревшей), без службы — Стоп и новый запуск.

Кнопка **Список** справа от игры открывает в Блокноте свой список игры в `user/` (если файла нет, он создаётся).

| Модуль | Что делает |
|---|---|
| Sky: Children of the Light | UDP игры (IP из `lists/ipset-sky.txt` и `user/ipset-sky.txt`) и WebSocket чата/заданий |
| Photon (UDP 5055-5058, 27000-27002) | UDP игр на серверах Photon: fake с TTL 8 |

### Списки IP игр

У игры два списка: стандартный `lists/ipset-<игра>.txt` (приходит с релизом и обновляется вместе с ним) и свой `user/ipset-<игра>.txt` (только ваши добавления). Правило берёт оба. Свой файл создаётся при запуске, установке службы, тестах или кнопкой **Список**: в нём комментарий и неиспользуемый адрес `203.0.113.113/32` — не удаляйте его, пустой список подходит под все IP. Добавляйте IP и подсети по одному в строке. winws2 перечитывает изменённый файл без перезапуска; для winws нужен Стоп и новый запуск.

### Sky: Children of the Light

Новые IP игровых серверов добавляйте в `user/ipset-sky.txt` (отдельные адреса `/32`).

Игроки, чат и задания проверены на `winws2`. Для `winws` флаги собираются, но в игре пока не проверены. Исправление DNS сервера входа (`hosts` или безопасный DNS) сохраняйте отдельно: модуль не подменяет DNS.

### Photon

Один профиль для игр на Photon (UDP 5055–5058 и 27000–27002): fake с TTL 8, первые 4 пакета, 6 повторов. С TTL 8 fake не доходит до сервера Photon. Без него игра может выкидывать в меню через несколько секунд после старта матча: в `Player.log` игры есть `On Disconnected cause: ClientTimeout`.

Опция **Только подсети Photon Cloud EU из списка** (по умолчанию выключена):

- выключена — правило для всех IP на этих портах. Так работал прежний общий профиль Photon, и так работают серверы вне Европы, которых нет в списке;
- включена — правило только для IP из `lists/ipset-photon.txt` и `user/ipset-photon.txt`. Остальной трафик на этих портах идёт без обхода.

Если игра на включённой опции выкидывает, найдите IP игрового сервера (UDP 5055–5058 или 27000–27002) и добавьте его подсеть в `user/ipset-photon.txt` или выключите опцию.

Правило с TTL 8 проверено на `winws2` для подсетей Photon Cloud EU (2026-10-24): матч и голосовой чат в лобби. Для всех IP (опция выключена) и на `winws` правило в играх пока не проверено. Голос, отключившийся до включения модуля, сам не переподключается: выйдите из пати и войдите снова или перезапустите игру.

## Файлы

| Путь | Роль |
|---|---|
| `zapman.exe` | GUI и трей |
| `strategies/` | Каталог: `flowseal/*.json` — стратегии, `games/` — игровые модули, `fakes/` — файлы `.bin` для fake. Argv для winws и winws2 собирается из одного JSON |
| `bin/` | `winws.exe`, `winws2.exe`, Lua, WinDivert. Теги и SHA256 — `bin/versions.json` |
| `lists/` | Сток-хостлисты, списки IP игр (`ipset-sky.txt`, `ipset-photon.txt`) и `*.default.txt` — начальные копии своих списков |
| `user/` | Свои списки, рабочий `ipset-all.txt`, активные fake, `config.json` (gitignore) |
| `test-results/` | Логи тестов |

Флаги `zapman.exe`: `--tray` — старт в трее; `-root <папка>` — папка с `bin`, `strategies`, `lists` и `user` (по умолчанию папка exe).

Движки — официальные [zapret](https://github.com/bol-van/zapret) и [zapret2](https://github.com/bol-van/zapret2).

Имена стратегий могут не совпадать с файлами [Flowseal/zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube). Смысл атак тот же, пока набор не сменили явно.

## Свои адреса

Файлы в `user/` создаются при запуске стратегии, установке службы и тестах, если их нет; списки игр — только для включённых модулей. Существующий файл программа не меняет.

- `user/list-general-user.txt` — домены (поддомены тоже).
- `user/list-exclude-user.txt` — исключить домен (если сеть уже в ipset).
- `user/ipset-all.txt` — IP и подсети (IPSet Filter). Нет файла — копия с `lists/ipset-all.default.txt`.
- `user/ipset-exclude-user.txt` — исключить IP и подсети.
- `user/ipset-sky.txt` — свои IP Sky в дополнение к `lists/ipset-sky.txt` (модуль Sky).
- `user/ipset-photon.txt` — свои подсети Photon в дополнение к `lists/ipset-photon.txt` (модуль Photon, опция списка). Файл создаётся и при выключенной опции.
- `user/fakes/ACTIVE_DISCORD_UDP.bin`, `user/fakes/ACTIVE_GAME_UDP.bin` — активные fake (окно **Fake...**). Нет файла — копия дефолта из `active` в `strategies/catalog.json`: `quic_initial_rutube_ru.bin` и `quic_initial_4pda_to.bin`.

Пустой список подходит под всё, поэтому новый файл без начальной копии получает одну неиспользуемую строку.

Обновление: скопируйте папку `user/` в новую распаковку. Файлы из старого `lists/` (`*-user.txt`, рабочий `ipset-all.txt`) и корневой `config.json` программа не читает.

Модуля Sker больше нет, его заменяет Photon. Если в `user/config.json` осталось `"games": ["sker"]`, запуск и установка дают ошибку поля `games`: откройте **Игры...**, отметьте Photon и нажмите OK. Свои подсети из старого `user/ipset-sker.txt` перенесите в `user/ipset-photon.txt`; старый файл программа не читает. Старый `user/ipset-sky.txt` был полной копией стандартного списка; теперь стандартный список берётся из `lists/`, и копию можно очистить (оставьте строку `203.0.113.113/32`).
