# Инструкции для агентов

**Основное правило:** написанный код в первую очередь должен быть поддерживаемым. Ясный текущий интерфейс важнее совместимости обвязки, обходных путей и «на всякий случай». Если правка усложняет чтение или правку без необходимости — не делайте её так.

Этот репозиторий — Windows-сборка zapret. Целевая раскладка и критерии готовности — в [`PLAN.md`](PLAN.md): в корне **два** `.bat` — `zapret.bat` (GUI) и `cli.bat` (консоль). Всё остальное — `.ps1`.

Пишите код и правки так, чтобы агент и человек могли опереться только на **текущий** интерфейс. Старые флаги, API и раскладку файлов не сохраняйте. Исключение — **набор стратегий** (см. ниже).

## Статус: alpha (совместимость)

Проект в **alpha**. Пока пользователь явно не отменит эту политику:

1. **Обратная совместимость только у стратегий.** Сохраняйте сам набор стратегий обхода (что они делают с трафиком), в том числе при переносе на zapret2 / Lua / `.ps1`. Имена файлов и подписи в GUI **можно менять**. Не требуются алиасы старых имён (`general (ALT5).bat` → то же имя навсегда).
2. **Во всём остальном совместимости нет.** Не сохраняйте старые флаги CLI, поля API, ключи пресетов, переменные окружения, имена служб и раскладку файлов «ради существующих пользователей».
3. **Удаляйте, не делайте прокладки.** При переименовании или замене опции обвязки удалите старый путь. Без алиасов, тихих fallback, двойного чтения и предупреждений об устаревании, которые оставляют оба поведения. Не держите `foo.bat` рядом с `foo.ps1`. **Исключение:** `winws` и `winws2` в `bin/` оба нужны — [`PLAN.md`](PLAN.md) (движки). Стратегию не плодите вторым файлом «для другого движка»: два argv в одном `.ps1`.
4. **Ломающие изменения фиксируйте в [`CHANGELOG.md`](CHANGELOG.md)** в датированной секции или в `Unreleased` (Added / Changed / Removed / Breaking). Смену имени стратегии пишите в Changed (старое → новое). Потерю стратегии без преемника — в Breaking и только осознанно.
5. **Документацию обновляйте в том же изменении** — `README.md`, этот файл, [`PLAN.md`](PLAN.md), примеры в `lists/` и файлы стратегий — чтобы они описывали только текущий интерфейс.

Если неясно, относится ли вещь к «стратегии» или к «обвязке»: стратегия — сценарий обхода (`strategies/*.ps1`, оба движка). Всё остальное — обвязка, её старую форму выбрасывайте.

## Среда выполнения

Целевой интерпретатор — **Windows PowerShell 5.1** (`powershell.exe`), не PowerShell 7 (`pwsh`).

| Платформа | Ожидание |
|---|---|
| Windows 10 LTSC (и новее с рабочим столом) | Работает без допнастроек: inbox PS 5.1, .NET 4.x, WinForms, CIM |
| Windows 7 SP1 x64 | Нужны допнастройки: WMF 3.0+ (лучше WMF 5.1) и .NET 4.5+ |
| PowerShell 7 | Не цель. Не используйте синтаксис только для `pwsh` (`??`, `?:`, `&&` / `\|\|`, `-Parallel`) |

Ограничения 5.1, которые уже ломали GUI:

- `return @(...)` разворачивает массив из 0/1 элемента. Для `.Count` оборачивайте в `@()` **в месте использования**.
- `Set-StrictMode -Version Latest` запрещает обращение к несуществующим свойствам.
- `Get-Item HKLM:\...` открывает ключ только на чтение. Для записи — `OpenSubKey(..., $true)`.
- `$PSScriptRoot`, `Get-CimInstance`, `-LiteralPath` требуют минимум PowerShell **3.0**.
- WinForms нужен **STA**: `powershell.exe -STA`. Вход — `zapret.bat`.
- Комментарии в коде — [ASD-STE100](https://www.asd-ste100.org/) Simplified Technical English. Политику (PS 5.1, не `pwsh`, совместимость стратегий) пишите в этом файле, не копируйте её в каждый `.ps1`.
- [`src/Zapret/Ui.ps1`](src/Zapret/Ui.ps1) с русскими строками — **UTF-8 с BOM**. Без BOM PowerShell 5.1 ломает литералы.

## Линтер

После правок `.ps1`, `.bat`, `src/Zapret/`, `strategies/` или `dev/` прогоните линтер и исправьте все FAIL до конца задачи:

```text
powershell.exe -NoProfile -ExecutionPolicy Bypass -File dev\lint.ps1
```

`dev/lint.ps1` всегда ловит PS 5.1/WinForms: `List[object]`, `$form.Enabled = $false` / `Hide()` / `ShowDialog()` у главного окна, BOM у кириллицы/`Ui.ps1`, синтаксис `pwsh`. Опционально: PSScriptAnalyzer; Blinter для `.bat` (`pipx install Blinter`, [`blinter.ini`](blinter.ini)).

## Раскладка

**Цель:** в корне только `zapret.bat` (GUI) и `cli.bat` (консоль). Новый `.bat` не добавлять. Логика — `.ps1`.

| Путь | Роль |
|---|---|
| `zapret.bat` | GUI: один `powershell.exe -STA` → `src/utils/gui.ps1` (версия, среда и окно в том же процессе) |
| `cli.bat` | Консоль: проверка `powershell.exe`, затем это окно — PowerShell (`src/utils/cli.ps1`) |
| `src/utils/cli.ps1` | Меню или `service` / `tests` / `env` в том же процессе |
| `src/utils/gui.ps1` | WinForms |
| `src/Zapret/` | Модуль: служба, фильтры, диагностика, тесты, UI. В `src` только исходники |
| `config.json` | Язык, `engine` (`winws` / `winws2`, окно стратегий), фильтры, Auto-Update Check, цели тестов |
| `test-results/` | Логи тестов (на лету) |
| `src/utils/service.ps1` | Консольное меню (как GUI). Elevate — этот файл, не `cli.ps1` |
| `src/utils/test zapret.ps1` | Консоль тестов → `Invoke-ZapretStrategyTests` (ненулевой exit, если прогон не удался) |
| `dev/lint.ps1` | 5.1/WinForms + PSSA + Blinter |
| `dev/update-zapret.ps1` | Официальные zip zapret / zapret2 → `bin/` + [`bin/versions.json`](bin/versions.json). Fake `.bin` не трогает. |
| `strategies/*.ps1` | Стратегии: argv для выбранного `engine` (`winws` / `winws2`) |
| `lists/` | Хостлисты и ipset. Рабочий `ipset-all.txt` локальный; в git — `ipset-all.default.txt`. Нет файла — копия с default. Есть — его и берём. `*-user.txt` создаются на лету |
| `bin/` | `winws.exe` (zapret v72.13), `winws2.exe` + `lua/` (zapret2 v1.0.4), общий WinDivert. Хеши — [`bin/versions.json`](bin/versions.json), сверка при старте |

Новая логика — только `.ps1`. GUI не парсит флаги: запускает файл или ставит службу. Exe — из `engine` в [`config.json`](config.json) ([`PLAN.md`](PLAN.md)).

## GUI: обязательное поведение

- **Remove Services:** сначала `zapret` и `winws`, потом WinDivert / WinDivert14. Иначе драйвер зависает в `STOP_PENDING`.
- **Install Service:** дождаться удаления старой службы; ImagePath из шаблона (`"exe" args`; для winws2 ещё `--chdir` на `bin/`); проверить запись в реестр; при сбое откатить `sc delete`.
- **Главное окно:** без списка стратегий. **Старт службы** (выключен, если службы нет) / **Стоп** / **Снять службы** / **Стратегия…**. Смена стратегии = Install из окна стратегий.
- **Стратегия…:** список `strategies/*.ps1`. **Запустить выбранную** останавливает службу/winws и стартует файл (без автозапуска). **Установить службу** закрывает диалог. **Прогнать тесты** снимает службу и открывает тесты с главного окна. Список выделяет запущенную или установленную.
- **Game Filter** и **движок** при установленной службе зашиты в ImagePath: нужен повторный Install, не просто Stop/Start. Фильтр — диалог с кнопкой применения. Движок — в «Стратегия…».
- **IPSet** читается из файла при старте: достаточно Stop/Start. Режимы: `none` / `loaded` / `any`. Backup — rename, не «вечная» копия.
- **Settings:** Game Filter, IPSet, Auto-Update Check, подмена fake. **Стратегия…:** список + `winws` / `winws2`.
- **Tools:** скачать ipset, сверить hosts, проверить версию, диагностика (список с галочками; **Запуск** у чисток, **ОК** пропуск). Клик по Status — полный статус и журнал. Логика общая с `src/utils/service.ps1` — `src/Zapret/`.
- **Язык:** RU/EN, `Get-ZapretUiString` в модуле. Переключатель на главном. Язык, `engine`, Game Filter, Auto-Update Check и цели тестов — [`config.json`](config.json) в корне.
- **Окно:** крестик = выход; свернуть = панель задач. Трей, пока жив GUI: Открыть / Выход (службу не снимает). Главный цикл — `Application.Run($form)`, не `$form.ShowDialog()` (дочерний `ShowDialog` выключает владельца и роняет UI). Не `Hide()` и не `$form.Enabled = $false`. Тесты: без событий `Process` в scriptblock (пул потоков + STA). В PS 5.1 не писать `New-Object System.Collections.Generic.List[object]`.

## Что не делать

- Не добавлять зависимость от `pwsh`, WinUI, .NET SDK или Visual Studio, если это ломает LTSC без допнастроек.
- Не сохранять обвязку (старые `.bat` лаунчера/службы, ключи реестра, раскладку `lists/`) через shim. Набор стратегий переносите; имена стратегий менять можно.
- Не писать эксплойты и не изобретать DPI-стратегии. Не писать компилятор Lua→флаги winws1, пока в [`PLAN.md`](PLAN.md) нет доказанного подмножества. Не подменять отсутствующий argv другого движка.
